# CLAUDE.md - Project Instructions

## Repository

**Primary Repository:** https://github.com/mrblonde3/mp-ai-clone

Always push to this repository using the `mrblonde` remote until instructed otherwise.

```bash
git push mrblonde main
```

## Project Overview

This is the MP Digital Solutions website - a Next.js marketing site for an AI automation consultancy.

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion (animations)
- i18n (English + Slovak)

## Key Files

- `content.ts` - All website copy (EN + SK translations)
- `types.ts` - TypeScript interfaces
- `components/` - React components
- `app/` - Next.js app router pages

## Commands

```bash
npm run dev      # Start development server
npm run build    # Production build
npm run lint     # Run ESLint
```
